# Manual test — start date on Project progress cards (15 Oct 2026)

1. Sign in as staff and open **PC Command → Project Progress** (`/pc/flow`).
2. In **02 Booking confirmed** and **03 Pre-start**, every card with a start date shows a line under the money, e.g. **Starts Tue 20 Oct**. A booked job with no start date shows no line.
3. In **04 In progress** and later lanes the line reads **Started …** with the same date.
4. Open a job, change its start date, return to Project Progress: the line follows the new date (and the card moves lanes as before once within 7 days).
5. A start date in another year shows the year: **Starts Mon 4 Jan 2027**.
