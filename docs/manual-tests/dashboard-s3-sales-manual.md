# Manual test — Home dashboard v2 · session 3 (Sales + funnel + activity)

No migration this session.

1. **As the master**: Sales shows four tiles (Estimates sent, Sales $, Sales number, Conversion) and two lists
   (Average order value by category, By salesperson) plus the **September target** card with the bar chart.
   Set a target under Settings → Dashboard and reload: the card shows $ hit, % hit and the pace marker.
   Remove it: the card reads "no target set", never 0%. **Show as table** lists the twelve months.
2. **Mine / Team**: press Mine — By salesperson and Conversion narrow to your own sends. Team restores all.
3. **As a sales login** (Sales ticked only): lands on Mine; no target card; Where estimates go shows the
   funnel with drop-off notes and the median sent-to-accepted days.
4. **Activity**: open a sent estimate's link in a private window; within five seconds the master's and a
   sales login's Activity shows "<customer> — Estimate opened" (family Estimates). Chips narrow to one
   family; the search box narrows by customer; Export CSV downloads the rows on screen. A finance login
   sees only Money and Messages chips.
5. **Exports**: every list's Export CSV carries the period, Mine/Team and the activity filters in its link.
