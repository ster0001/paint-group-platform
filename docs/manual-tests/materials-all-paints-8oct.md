# Manual test · every paint on every list, and a search in the substrate (8 Oct 2026)

Branch `feat/materials-all-paints-search-8oct`. No migration.

1. Open any estimate with an interior room. **Materials** card at the top: the paint dropdown on an **Int** row lists exterior products too (e.g. Weathershield), A–Z. Pick one: it takes and stays.
2. Type in the search box at the top of the card: `haymes`, then `low sheen`, then part of a name. Every dropdown on the card narrows, including **Other paints**. The paint a row is already set to stays listed whatever you type. Clear the box: the whole list is back.
3. Open a room, click a surface (**Edit Surface**). Under **Product · Estimated paint**, a search box sits above the Product list. Type part of a name: the list narrows. Pick one; clear the box; it is still selected.
4. Open a line item's **Materials for this line**: its product list also offers interior and exterior paints alike.
