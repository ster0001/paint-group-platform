# Homepage v2 — session 3 (Settings → Showcase) · manual test for Tom

This is the "publish one real job end-to-end" step of the definition of done
(brief §7 2b). Do it on production once migration 20270101 has run (it has).

## Publish your first real job

1. Settings → Company → **Showcase jobs** → "Open showcase jobs →".
   (If you ran the placeholder seed you'll see three drafts; otherwise the
   list is empty.)
2. **+ New job** (or open a draft). The form is in the same order as the page
   a visitor reads — fill it top to bottom:
   - Upload the finished photo. Tick "The customer has agreed…". Without the
     tick you cannot publish (⚑9.11).
   - Title, job type, home/business, suburb. Leave the web address blank —
     it is made from the title and suburb. It locks once published.
   - Month completed, days on site.
   - Price range in whole dollars, inc. GST. The line under it shows exactly
     how it will print.
   - Scope line (one line, 90 characters), summary (2–4 sentences).
   - What we did: "+ Add an area", one row per area, drag to reorder.
   - Gallery: "Add photos" (several at once), set before/during/after and a
     caption, drag to reorder.
   - Colours, condition notes, customer line — all optional.
   - Link to the estimate — optional now; it will let the "Get a price like
     this" button start from the real scope (session 4).
   - Featured: 1, 2 or 3 to make it a homepage card. If a spot is taken you
     are asked which job to replace.
3. Watch the **right-hand preview** as you type (on a laptop); on a phone
   tap **Preview**. It is the actual page, not a mock-up.
4. Tick **Published** and press **Save & publish**. The status line says
   "Published — live at /work/…". (The public page itself arrives in session
   4 — today only the data is live.)

## What to check

- Untick Published and save: the status says "Saved as a draft"; the job
  stays in the list as Draft.
- Try to publish a job with no photo: the checklist under the Published tick
  lists what's missing and Save refuses with the same list.
- Give two jobs the same featured spot: the "spot is taken" dialog names the
  current holder.
